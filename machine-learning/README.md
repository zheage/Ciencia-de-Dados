# 🤖 Machine Learning

Anotações sobre algoritmos, técnicas e avaliação de modelos.

## Tópicos

### Supervisionado (`supervisionado/`)
- Regressão linear e logística
- Árvores de decisão e ensemble (Random Forest, XGBoost)
- SVM e KNN

### Não Supervisionado (`nao-supervisionado/`)
- K-Means e clusterização hierárquica
- PCA e redução de dimensionalidade
- Detecção de anomalias

### Avaliação de Modelos (`avaliacao/`)
- Métricas de classificação (AUC, KS, Gini)
- Cross-validation e overfitting
- Calibração de probabilidades
