# 📐 Matemática

Anotações de matemática com foco em fundamentos para machine learning e estatística.

## Tópicos

### Álgebra Linear (`algebra-linear/`)
- Vetores e matrizes
- Decomposições (SVD, LU, QR)
- Autovalores e autovetores

### Cálculo (`calculo/`)
- Derivadas e regra da cadeia
- Gradientes e derivadas parciais
- Otimização via cálculo

### Otimização (`otimizacao/`)
- Gradiente descendente e variantes
- Métodos de segunda ordem
- Otimização convexa
