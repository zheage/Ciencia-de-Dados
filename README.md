# 📚 Data Science Notes

Repositório de anotações pessoais em Ciência de Dados, Matemática e Estatística — com foco em aplicações práticas em risco de crédito e portfólio profissional.

## 🗂️ Estrutura

| Domínio | Descrição |
|---|---|
| [📐 Matemática](./matematica/) | Álgebra linear, cálculo e otimização |
| [📊 Estatística](./estatistica/) | Probabilidade, inferência, bayesiana e séries temporais |
| [🤖 Machine Learning](./machine-learning/) | Modelos supervisionados, não supervisionados e avaliação |
| [💳 Risco de Crédito](./risco-de-credito/) | PD/LGD/EAD, scorecards, validação e regulatório |
| [🧱 Databricks](./databricks/) | Delta Lake, Medallion Architecture, Feature Store e MLflow |

## 🛠️ Tecnologias

- Python 3.10+
- Jupyter Notebooks
- Principais libs: `numpy`, `pandas`, `scikit-learn`, `statsmodels`, `matplotlib`, `seaborn`

## ⚙️ Como usar

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/data-science-notes.git
cd data-science-notes

# Instale as dependências
pip install -r requirements.txt

# Abra o Jupyter
jupyter notebook
```
